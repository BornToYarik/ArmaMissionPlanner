Загрузите миссию в планировщике
3D-планирование

WASD — перемещение · Q/Z — вверх/вниз · Shift — быстрее · колесо — к курсору · ПКМ — поворот. Обведите бойцов ЛКМ; Shift добавляет к выбору.

Никто не выбран

Параметры движения и вместимость берутся из конфигов вашей сборки. Перетащите пехоту на машину для посадки.

Маршрут по этапам

Выберите бойцов, нажмите «Маршрут» и укажите точку.

Обзор с позиции

ПКМ на карте: «Из глаз» — 1,7 м, «Из техники» — 2,3 м.

Дальность:

У каждой точки своя пара цветов: видимо / закрыто. Серый — данных не хватает. Одновременно показываются до четырёх слоёв; остальные можно включать по очереди. Это оценка по рельефу и геометрии моделей, без травы и погодной маскировки.

Куда успеет противник

Обзорная оценка по рельефу и дорогам, без отдельных зданий, пробок и боевых остановок. Пустая техника без стороны относится к ближайшей стартовой группе в пределах 150 м, только если рядом нет другой стороны.

История на этой карте

Время и обзор — расчётная оценка. Шаг сетки и неполные данные показываются после подготовки.
