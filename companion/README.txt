WOG 3D Planner — тестовая версия для Windows x64

Распакуйте папку целиком. Запустите WOG-Planner.exe и выберите PBO миссии.
В браузере откройте «Тактическая карта и Техника» → «3D · маршруты и видимость».
Для оригинальных объектов и параметров выберите папки установленной игры и
используемых модов, затем подготовьте модели. Качество: низкое, среднее, высокое.
Утилита только читает файлы Arma. Игровые ассеты не входят в архив и не отправляются
на сервер. Карты, общие модели и исторические записи подгружаются с WOG Replay.

Управление:
  ЛКМ на модели или метке — выбрать. Отделения и техника выбираются в списке справа.
  Shift добавляет/убирает выбор; рамка мышью выбирает несколько юнитов.
  Двойной щелчок по бойцу выбирает отделение.
  Пехоту можно перетащить на машину, если в конфиге определена вместимость.
  Короткое нажатие ПКМ на карте — действия у этой точки.
  Удержание ПКМ — поворот, средняя кнопка — перенос, колесо — зум к курсору.
  WASD — движение камеры, Q/Z — вверх/вниз, Shift — быстрее.
  ПКМ → Обзор пехоты (1,7 м) / Обзор техники (2,3 м):
  цветная проекция на рельефе, своя палитра у каждой точки.
  Щелчок на метке обзора открывает вид с этой позиции.
  Скрыть/показать проекцию можно через ПКМ по метке.
  ПКМ по метке обзора → Смотреть из этой точки; дальность взята из миссии.
  Вращение ПКМ, увеличение колесом и +/− (включая NumPad), выход Esc.
  В оптике заливка и кольцо курсора скрыты. Маски берутся из установленной игры.
  Обзор и точки маршрута можно перетаскивать и удалять через ПКМ.
  При перемещении обзора сохраняется полная детализация расчета.
  Достижимость: по пять дальних позиций трёх самых быстрых юнитов стороны,
  с теми же зданиями, стенами, камнями и объектами миссии, что и в маршрутах.
  Маршрут: точка → выбор варианта → ещё точка или завершение.
  Ручной путь: клики ЛКМ; ПКМ отменяет последнюю точку; Esc отменяет путь.
  Клик внутри 5-метрового круга конечной точки завершает путь.
  Воздушная техника идет прямо в XY с запасом над рельефом (оценка).
  Каждому юниту назначаются свои точки. Видны только маршруты выбранных.
  Выберите часть группы, чтобы продолжить её отдельной ветвью.
  Линейка: щелчок закрепляет начало, мышь двигает конец с текущей длиной,
  второй щелчок закрепляет результат; следующий начинает новое измерение.
  Escape отменяет текущий незавершённый этап.

«Настройки и история» открывает дополнительные параметры, исторические записи,
сохранение и открытие плана. Переключение вкладок сохраняет 3D-план в памяти.
2D показывает спутниковую карту (или локальные топографические тайлы). Метки
и выбранные маршруты общие с 3D; обзор в 2D не переносится.
Список справа сворачивается, фильтруется по стороне; ПКМ перемещает камеру.
Нейтральная техника доступна обеим сторонам. Названия учитывают расстановку.
Перед закрытием страницы сохраните план в файл. Теги из таблицы распределения
слотов показываются на 3D-метках.

Ограничения тестовой версии:
  Время пути — оценка с уклонами, поворотами, разгоном и торможением,
  а не полная физика Arma. maxSpeed берётся из конфигов, коэффициенты движения
  по поверхности и характеристики пехоты пока оценочные.
  Маршрут рассчитывается по сетке; её шаг выводится после расчёта. Узкие проходы,
  мосты, разрушаемые ограждения и динамические скрипты требуют проверки.
  Обзор использует уже загруженные камерой модели, без отдельной загрузки.
  Расчёт трёхмерный: вид вверх/вниз, дальность по сфере вокруг глаз/прицела.
  На экране только проекция на землю; лучи и оболочка сферы не рисуются.
  Углы поворота конкретной башни не ограничиваются.
  Незагруженная и закрытая земля остаётся без заливки. До четырех слоев.
  Объекты ниже 1,4 м прозрачны для расчета; кроны/кусты сплошные, окна закрыты.
  При подготовке сборки расчётная геометрия крон берётся из самого подробного
  визуального LOD независимо от выбранного качества картинки.
  Трава, погода, пробиваемость и
  маскировка не моделируются. Модель без ассета показана заменителем.
  Начальные объекты читаются из SQM; произвольные SQF-скрипты не исполняются.
  Сохранение плана не изменяет PBO и не публикует его автоматически.

Исходный репозиторий: BornToYarik/ArmaMissionPlanner,
ветка feature/wog-3d-planning. Серверы и FTP WOG этой утилитой не изменяются.
